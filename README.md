# 🛠️ TextTools – Text Manipulation Utility

## 🔗 Live Demo
[Explore TextTools Live](https://texttools-iota.vercel.app/)

## ✨ Features
- ⚡ **Instant Execution:** Real-time text transformation using optimized client-side regex patterns.  
- 🗣️ **Text-to-Speech:** Native browser voice rendering for reading treated text aloud.  
- 📋 **One-Click Actions:** Seamless system clipboard integration for immediate text copying.  
- 🔄 **State Synchronization:** Automatic data saving using local storage to preserve sessions across reloads.  
- 🧮 **Word Analysis:** Real-time character, word, and sentence counters with reading time metrics.  
- 📱 **Fully Responsive Layout:** Clean, intuitive UI built to adjust seamlessly to mobile and desktop screens.  

## 🛠️ Tech Stack
- **Frontend Framework:** React.js   
- **Styling UI:** Bootstrap   
- **Core Logic:** JavaScript (ES6+), Regular Expressions (Regex)   
- **Browser APIs:** Web Speech API, Clipboard API, Web Storage (Local Storage)
